# Aluguel de Carro

API REST de aluguel de veículos entre pessoas (peer-to-peer): proprietários 
cadastram carros, clientes alugam.

## Tecnologias
Java 17, Spring Boot, Spring Data JPA, H2, Swagger, Lombok

## Status

- ✅ CRUD de Proprietário
- ✅ CRUD de Veículo
- ✅ CRUD de Cliente
- ✅ CRUD de Aluguel (com cálculo automático de valorTotal)
